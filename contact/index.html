Reporting Hardware Diagnostic Anomalies

If you encounter unexpected test behavior—such as a 4000Hz/8000Hz mouse reporting rate caps, unusual keyboard matrix key combinations failing to register, or browser frame throttling—please include the following in your report:

  1. Peripheral Model: Exact mouse, keyboard, or switch model (e.g., Razer Viper V3 Pro, Wooting 60HE, Logitech G Pro X).
  2. Browser & Operating System: Chrome, Edge, Firefox, or Safari version, and OS (Windows 11, macOS, Linux).
  3. USB Configuration: Direct motherboard port, USB 2.0 vs 3.2 port, or USB hub topology.
  4. Observed vs Expected Result: Screenshot of the test scorecard or telemetry graph if applicable.
